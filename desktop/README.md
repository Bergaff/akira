# Akira для Windows

Отдельное приложение с интерфейсом. Оно использует общий движок экспорта, но хранит задания, чекпоинты, промежуточные данные и файлы **на компьютере**. Для локального режима Cloudflare, его аккаунт и оплаченный Workers не нужны. Сеть нужна для Discord и, по желанию, Telegram/Google Диска. В настройках можно дополнительно указать доверенный relay.

## Как пользоваться

1. Установите Akira, запустите приложение и в разделе «Настройки и секреты» задайте Discord token без префикса `Bot `. При желании настройте Telegram, Google Диск и Discord webhook. Пустое поле оставляет старое значение без изменений.
2. Выберите канал или сервер, ID автора, даты UTC и размер части. При необходимости включите пробный подсчёт. Нажмите «Создать и запустить».
3. Оставьте программу открытой и компьютер включённым. Можно свернуть окно. Пауза/продолжение и журнал доступны у каждого задания. При закрытии приложения экспорт прервётся; при следующем открытии незавершённые задания автоматически продолжатся. Во сне компьютера работа также останавливается и возобновляется после пробуждения.
4. Когда части готовы, нажмите **«Сохранить файлы…»** и выберите папку. Программа создаст отдельную подпапку и скопирует в неё готовые `.txt`. Если настроен Google Диск, после сборки части дополнительно копируются в указанную папку на Диске.

Ограничения Discord и последовательные запросы действуют и в локальном режиме: более мощный компьютер **не отменяет** паузы и rate limits Discord. Режим поиска Discord пока не реализован. На сервере порядок между каналами не глобальный, а полнота зависит от доступа к каналам и тредам. Не выключайте компьютер во время выгрузки; отключение или внезапная остановка могут потребовать восстановления после запуска. Учитывайте свободное место: кроме итоговых файлов временно хранятся прочитанные страницы и буфер.

## Безопасность

Секреты сохраняются через Electron `safeStorage`, на Windows — средствами шифрования Windows для текущей учётной записи пользователя. Они не записываются в открытый JSON и не показываются повторно. Тексты и чекпоинты не зашифрованы и находятся в папке данных программы текущего пользователя (`%APPDATA%`); защита зависит от прав Windows и безопасности компьютера. У приложения нет отдельного пароля — используйте пароль вашей учётной записи Windows. Не передавайте токен другим людям. Программа не обходит капчи. Автоматизация пользовательского токена может нарушать условия Discord; ответственность лежит на владельце аккаунта.

Удаление задания в приложении удаляет его локальные служебные данные и части из хранилища приложения. Копии, уже сохранённые в выбранную вами папку или на Google Диск, не удаляются. Настройки можно удалить отдельной кнопкой в интерфейсе. Про работу Telegram и OAuth Google см. [главный README](../README.md).

## Сборка установщика

Windows x64, Node.js 22.12+ и npm:

```powershell
npm ci
npm run desktop:typecheck
npm test
npm run desktop:dist:win
```

Результат — `desktop/release/Akira-Setup-0.1.0-x64.exe`. Установщик по умолчанию не подписан коммерческим сертификатом, поэтому Windows SmartScreen может показывать предупреждение. Убедитесь, что файл получен из вашего доверенного репозитория. На GitHub предусмотрен workflow **Build Windows desktop**, создающий скачиваемый artifact `Akira-Windows-Setup`; артефакты workflow хранятся ограниченное время и не являются постоянным релизом.
